# DSA Note Formatting Rule

When creating or modifying notes in the `DSA` directory:

- Keep all formal definitions in **Proper English**.
- Write all explanations, analogies, step-by-step logic, code comments, and key points in **Hinglish**.
- Retain Obsidian tags (`#dsa`, `#java`), wikilinks (`[[...]]`), LaTeX math (`$O(N)$`), and code formatting.
